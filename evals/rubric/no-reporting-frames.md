Pass only if claims are stated directly, as someone asserting them would word them. Fail if a claim about the world is wrapped in a reporting frame such as "X argues that", "critics claim", "I found that", or "a popular belief holds", unless that statement is an attribution child (a `+3` child whose parent states the same claim directly) or is genuinely about the speaker's own reasoning process, such as which evidence a judge weighted most.
